# ROADMAP

This file is the operating roadmap for LLCAtlas. `README.md` remains the strategic source of truth; this file translates it into execution windows and should be refreshed quarterly.

Last updated: 2026-05-19

Update cadence: review monthly, refresh quarterly, and update after major data milestones or phase changes.

## Current Strategic Shift

LLCAtlas keeps the same name, domain, stack, audience, and affiliate model. The scope changes from state-guide expansion to a tools-first funnel:

- Calculators are the primary moat.
- State guides are acquisition support, not the main build track.
- New state-guide expansion is paused after the current 10 guides are polished.
- Month 1 priority is measurement, funnel plumbing, and the new S-corp election savings calculator.
- Astro, GitHub Pages, static rendering, and no backend remain locked.

## Month 1 Outcome

By the end of Month 1, LLCAtlas should be a measurable funnel with one new flagship calculator.

Done means:

- Cloudflare Web Analytics installed.
- Google Search Console verified.
- Affiliate outbound click tracking live.
- Affiliate data-attribute convention documented and used.
- Affiliate disclosure audited across existing pages.
- Buttondown/newsletter intentionally parked until traffic or a lead magnet justifies it.
- S-corp election savings calculator shipped.
- Northwest vs Bizee comparison page shipped.
- Current 10 state guides reviewed for internal links and downstream CTA.
- Calculator template locked from the S-corp calculator.
- `THIS_WEEK.md` updated during each Sunday review.

## 30-Day Tracks

### Track A: Audit And Plumbing

- Verify deploy path and production URL behavior.
- Confirm Cloudflare Web Analytics edge injection is active.
- Add outbound click event handling.
- Add or document GSC verification.
- Audit affiliate links for `rel`, provider data, placement data, and working URLs.
- Audit footer disclosure across every page.
- Park Buttondown capture shell until the site has meaningful traffic.

### Track B: Flagship Calculator

- Build the S-corp election savings calculator.
- Make it the reusable calculator template.
- Include a clear output decision, not just a number.
- Route users to the right formation/comparison CTA.
- Link it from existing calculator, tax, and state-guide pages.

## Month 2 Direction

- Improve the top calculator pages based on Month 1 implementation lessons.
- Ship priority comparison pages if affiliate tracking is working.
- Add reasonable compensation and LLC-vs-sole-prop calculators.
- Keep state-guide work limited to polishing, linking, and sitemap/indexing cleanup unless data says otherwise.

## Month 3 Direction

- Add lead magnets around the highest-intent calculator clusters.
- Expand comparison pages only where there is a clear downstream affiliate target.
- Review GSC and Cloudflare Web Analytics data before expanding any new content cluster.
- Do not start Phase 2 operations affiliates until the core formation funnel is measurable.

## Quarterly Review Questions

- Which pages generate affiliate clicks per 1,000 visitors?
- Which calculators have impressions but weak click-through?
- Which pages are orphans under the 5-in/5-out internal-linking rule?
- Is the brand still mostly LLC/formation/tax, or drifting into broader founder tools?
- Is any infrastructure idea saving publishing time within 30 days?
